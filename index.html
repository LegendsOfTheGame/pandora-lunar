How this works

This tracker is completely self-serve. Add your own character (up to 3), and everything you type is saved only in this browser, on this device — nothing is sent anywhere, and no other FC member can see it.

Adding a character

Click + Add character above. Give it a name, then fill in whatever sections matter to you — nothing is required. Click the × next to a character's name to remove it.

Three-character limit

Each browser can hold up to 3 characters. If you play more than 3 and want to track them all, use a second browser (e.g. Firefox alongside Edge) — each one keeps its own completely separate storage, so nothing overlaps.

Backing up your data

Click Download backup any time to save a .json file with everything. Restore from file loads one back — useful for moving to a new device or recovering from a cleared browser. Clearing your browser's site data will erase your tracker, so back up before you do that.

Routines & MSQ progress gating

The Routines section is for anything that repeats on the game's reset schedule (dailies, weeklies) — it clears itself automatically, on real UTC reset times. The requires field lets you hide a routine until you've reached a given point in the story — set the MSQ progress box next to your character's name first (it takes a patch number like 5.3 as a stand-in for how far along you are, not necessarily the current live patch).
